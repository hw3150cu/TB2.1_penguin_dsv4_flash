Here's a setup that turns a bare Git repo on the server into a deployment pipeline:

```
[push] → bare repo /git/server → post-receive hook → /var/www/server → HTTP server on :8080
```

I'll assume Ubuntu/Debian-style commandsched; adjust for your distro.

## 1. On the server: install Git and create the bare repo

```bash
sudo apt update
sudo apt install -y git

sudo mkdir -p /git
sudo chown $(whoami):$(whoami) /git

# --initial-branch keeps the default branch named "master"
git init --bare --initial-branch=master /git/server
```

Make sure the SSH user you'll connect as owns `/git` and `/git/server` so `git push` works over SSH.

## 2. Create the web root

```bash
sudo mkdir -p /var/www/server
sudo chown $(whoami):$(whoami) /var/www/server
```

## 3. Add the post-receive hook

Create `/git/server/hooks/post-receive`:

```bash
cat > /git/server/hooks/post-receive <<'EOF'
#!/bin/sh
set -e

DEPLOY_DIR=/var/www/server

# Export the pushed branch content into the web root
git --work-tree="$DEPLOY_DIR" checkout -f

echo "Deployed to $DEPLOY_DIR"
EOF

chmod +x /git/server/hooks/post-receive
```

This runs every time a push is received)Skip the URL and deploys the contents of the repo into `/var/www/server`.

## 4. Serve `/var/www/server` on port 8080

Choose one of these:

### Option A: Python's built-in HTTP server (simplest)

```bash
cd /var/www/server
python3 -m http.server 8080
```

If you want it to keep running in the background:

```bash
nohup python3 -m http.server 8080 --directory /var/www/server &
```

For a permanent service, put that in a systemd unit or run it inside `tmux`.

### Option B: nginx

```bash
sudo apt install -y nginx

sudo tee /etc/nginx/sites-available/server8080 > /dev/null <<'EOF'
server {
    listen 8080;
    server_name _;
    root /var/www/server;
    index index.html;
}
EOF

sudo ln -s /etc/nginx/sites-available/server8080 /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

Make sure port 8080 is open in the firewall/security group if `server` is remote.

## 5. From your computer

Since SSH login is already set up, run:

```bash
git clone user@server:/git/server
cd server

echo "hello world" > hello.html
git add hello.html
git commit -m "add hello.html"
git push origin master
```

Then verify:

```bash
curl http://server:8080/hello.html
```

You should see:

```
hello world
```
