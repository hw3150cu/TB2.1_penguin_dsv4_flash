## How it works

The file is valid in both languages using two complementary tricks:

1. **C side** — The leading `# /*` through `# */` lines form a C block comment that swallows the `"""` (which would otherwise be invalid C / trigger GCC warnings). 2. **Python side** — `#` is a comment, so the `# /*` lines are ignoredchers. The `"""` opens a triple-quoted string that swallows the entire C source, and the matching `"""` after the C code closes it. The remaining `import`, `def`, and `print` are real executable Python code.

The Fibonacci logic is an identical iterative implementation in both languages:
- `f(0) = 0`, `f(1) = 1`
- `f(n) = f(n-1) + f(n-2)`
