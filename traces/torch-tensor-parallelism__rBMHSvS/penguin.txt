    @staticmethod
    def forward(ctx, tensor):
        world = dist.get_world_size()
        if world == 1:

        tensors = [torch.empty_like(tensor) for _ in range(world)]
        dist.all_gather(tensors, tensor.contiguous())
        return torch.cat(tensors, dim=-1)
    @staticmethod
    def backward(ctx, grad_output):
        world = dist.get_world_size()
        if world == 1:
            return grad_output
        chunk_size = grad_output.size(-1) // world

class _AllGatherLastDim(torch.autograd.Function):
    @staticmethod
    def forward(ctx, tensor):
        world, _ = _get_world_info()
        if world == 1:
            return tensor
        tensors = [torch.empty_like(tensor) for _ in range(world)]
        dist.all_gather(tensors, tensor.contiguous())
        return torch.cat(tensors, dim=-1)

    @staticmethod
    def backward(ctx, grad_output):
        world, rank = _get_world_info()
        if world == 1:
            return grad_output
        chunk = grad_output.size(-1) // world
        return grad_output.narrow(-1, rank * chunk, chunk)

## `ColumnParallelLinear`
- Splits the weight/output dimension across ranks.
- If the master weight is `[in_features, out_features]`, it slices **columns** (`master[:, start:end]`).
- If given in the PyTorch `nn.Linear` layout `[out_features, in_features]`, it takes the matching row slice and transposes during `forward`, preserving the same tensor-parallel data flow.
- Each rank computes its local output shard, adds its **sharded zero-initialized bias**, and the shards are concatenated along the last dimension with `all_gather`.

## `RowParallelLinear`
- Splits the weight/input dimension across ranks.
- With `[in_features, out_features]` it slices **rows**; with `[out_features, in_features]` it takes the matching column slice and transposes during `forward`.
- Each rank receives only its slice of input features, computes a partial output, then the partial outputs are summed with `all_reduce`.
- The **full zero-initialized bias** is added after the reduction (so it isn't multiplied by the world size).

## Additional details
- Custom `torch.autograd.Function`s wrap `all_gather` and `all_reduce` so gradients flow correctly through the distributed ops for both weights and biases.
- Handles `world_size == 1` gracefully (no collectives needed) and falls back to a single process if the default process group isn't initialized.
- Bias is initialized to zeros with the same dtype/device as `master_weight`.
- Raises clear errors if the shard size isn't divisible by the world size.
