## Attack overview

I implemented a chosen-plaintext differential attack in `/app/attack.py` that recovers `key[5]` in about **0.12 seconds**.

**Key insight about the cipher:**
- The `f`-function has a deterministic differential (probability 1):
  ```
  f(x) ^ f(x ^ 0x80808080) = 0x02000002
  ```
  This holds because each `g`-operation is `ROTL2((a + b + c) mod 256)`; toggling the MSB (XOR `0x80`) changes the sum by exactly `0x80 mod 256`, which rotates to `0x02`, and the XOR combinations in `f` cancel for two of the four bytes.

**Chosen plaintext pairs:**
I choose pairs with the 64-bit difference:
```
ΔPL = 0x02000002
ΔPR = 0x82808082   (= 0x02000002 ^ 0x80808080)
```
which gives `(ΔA0, ΔB0) = (0x02000002, 0x80808080)`. Through the first 3 rounds this propagates deterministically to the last-round input:
```
(ΔL4, ΔR4) = (0x80808080, 0x02000002)
```
regardless of the actual key/plaintext values.

**Extracting key[5]:**
Because of the final swap, from a ciphertext we can recover the value `R4` entering round 4 directly:
```
R4 = C_lower ^ C_upper
```
and then compute the observed round-4 differential:
```
ΔF4 = (C_upper ^ C_upper') ^ 0x80808080
```
For a candidate key, `ΔF4 = f(R4 ^ K5) ^ f(R4' ^ K5)`. Since each round key is `seed * 1234567 mod 2^32` with a 16-bit seed, there are only 65536 candidates; I scan them against the first pair (narrowing to ~400 candidates) and filter with a few more pairs until the unique `key[5]` remains.
