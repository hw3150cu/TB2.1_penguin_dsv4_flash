(Note: I initially tried `rewrite plus_n_O`, but because this Coq version states the lemma as `n = n + 0` rather than the older `n + 0 = n`, the rewrite went in the wrong direction — that was the cause of the first compile error. `apply` sidesteps this cleanly.)

**Inductive step:**
```coq

```
- `rewrite IHn'` replaces `n' + m` with `m + n'`, giving `S (m + n') = m + S n'`.
- `rewrite <- plus_n_Sm` uses `plus_n_Sm : forall n m, S (n + m) = n + S m` in reverse to turn `m + S n'` into `S (m + n')`.
- `reflexivity` closes the resulting identical goal.
