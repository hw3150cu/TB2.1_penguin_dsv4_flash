import torch.distributed as dist
import torch.nn.functional as F


def _get_hidden_size(model):
    config = getattr(model, "config", None)
    if config is not None:

def _send(tensor, peer, device, dtype):
    tensor = tensor.to(device=device, dtype=dtype).contiguous()
    reqs = dist.batch_isend_irecv([dist.P2POp(dist.isend, tensor, peer)])
    for req in reqs:
        req.wait()


def _recv(shape, peer, device, dtype, requires_grad=False):
    tensor = torch.empty(*shape, device=device, dtype=dtype, requires_grad=requires_grad)
    reqs = dist.batch_isend_irecv([dist.P2POp(dist.irecv, tensor, peer)])
    for req in reqs:
        req.wait()
    return tensor

## Implementation overview

**Layer partitioning (balanced)**
- Computes `layers_per_rank = ceil(num_layers / world_size)`.
- Rank `r` owns a contiguous slice `[r * layers_per_rank, (r+1) * layers_per_rank)` of `model.model.layers`.
- Rank 0 also handles the token embedding; the last rank additionally handles the final norm, `lm_head`, and loss.

**Forward phase (all microbatches first)**
- Rank 0 embeds each microbatch → `[mb, seq, hidden_size]`.
- Other ranks receive hidden states from the previous stage via `P2POp`/`batch_isend_irecv`.
- Each rank runs only its local transformer layers, storing `hidden_in`/`hidden_out` per microbatch.
- Non-last ranks forward the hidden state to the next stage; the last rank applies `norm → lm_head → F.cross_entropy`, scaled by `1 / num_microbatches`.

**Backward phase (all microbatches after all forwards)**
- Last rank: `loss.backward()`, then sends `hidden_in.grad` back to the previous stage.
- Intermediate ranks: receive the gradient of the stage's output hidden state, run `hidden_out.backward(grad_out)`, and send `hidden_in.grad` backward.
- Rank 0: receives `grad_out` and runs `hidden_out.backward(...)`, which also populates gradient for the embedding.

**Key details**
- Uses `torch.distributed.P2POp` + `torch.distributed.batch_isend_irecv` for inter-stage communication.
- All hidden states and gradients are cast to the given `device`/`dtype`; token IDs/targets are moved to the device while keeping integer dtype (required for embedding lookup and cross-entropy).
- No hooks are installed; the model's own layer modules are invoked directly so test hooks can observe activations.
- Handles `world_size == 1` by running the entire model on a single rank with no communication, and `world_size == 2` as a two-stage pipeline.
