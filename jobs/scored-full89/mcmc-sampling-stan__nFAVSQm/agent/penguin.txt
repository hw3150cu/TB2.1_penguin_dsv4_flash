Now data. Let's inspect full data.csv. 68 rows. We need to design hierarchical model:
- Likelihood: y_i ~ Binomial(n_i, theta_i) for each observation i.
- theta_i ~ Beta(alpha, beta) for each group.
- Prior: (alpha, beta) ∝ (alpha + beta)^(-5/2).

This is the classic "Binomial-Beta hierarchical model" from BDA3 (Gelman et al.) with prior p(alpha,beta) ∝ (alpha+beta)^(-5/2). It's improper? Actually the prior is a non-informative prior on alpha, beta (hyperparameters of Beta distribution). Model from "Bayesian Data Analysis" example: rat tumors. The standard HMC parameterization in Stan uses:
```
data {
  int<lower=1> J;
  int<lower=0> n[J];
  int<lower=0> y[J];
}
parameters {
  real<lower=0> alpha;
  real<lower=0> beta;
  vector<lower=0, upper=1>[J] theta;
}
model {
  theta ~ beta(alpha, beta); // implicit likelihood for theta
  y ~ binomial(n, theta);
  // prior on alpha,beta: (alpha+beta)^(-5/2) -> increment target: -2.5*log(alpha+beta)
  target += -2.5 * log(alpha + beta);
}
```
Actually in Stan, the prior density p(alpha,beta) ∝ (alpha+beta)^(-5/2) means unnormalized log density = -2.5 * log(alpha+beta). This can be added via `target +=`. Since alpha,beta are positive, we declare lower=0. Need to be careful: the Beta distribution in Stan expects positive real alpha,beta. This is the standard model.

Alternative formulation from BDA3 sometimes uses `theta` parameter vector and `alpha`, `beta` with prior. Some use:
```
theta ~ beta(alpha, beta);
```
This is equivalent to adding `J * lbeta(alpha, beta) + (alpha-1)*sum(log(theta)) + (beta-1)*sum(log1m(theta))`? Actually beta distribution density. In Stan we can write directly `theta ~ beta(alpha, beta);`.
